# Harbor

**本地优先的个人 AI Agent 工作台** —— 数据、密钥、会话全部留在你自己的机器上。

它不是聊天框套壳：每条请求都是一个**有台账、有计划、能中断、能接着做**的任务。
跑到一半可以暂停、可以改方向、可以看它到底调了什么工具、改了哪些文件；
断了能恢复，跑飞了有预算上限兜住。

## 给谁用

给**在自己电脑上干活、又不想把代码和密钥交给云服务**的人。
典型场景：让它在一个项目目录里读文档、改代码、跑测试、写总结 —— 你看得见每一步。

**它不是**：团队协作平台、云端 Agent、手机 App，也不是"全自动替你写完整项目"的那种东西。
它更像个记性很好、干活有台账的助手，决策仍然在你这边。

## 快速开始

**Windows 便携版**（不需要装 Node）：下载 Release 里的压缩包，解压，双击 `Harbor.exe`。
数据存在 exe 同级的 `data/` 里，换电脑整目录拷走即可。

**从源码跑**：

```bash
npm install
npm run dev        # 起 Vite + Electron（热更新）
npm run package    # 打成便携版 exe（dist-portable/）
```

第一次启动会引导你填模型供应商（任何 OpenAI 兼容接口都行），密钥用系统凭证库加密后存在本机。

## 能做什么

| | |
| --- | --- |
| **有台账的任务** | 每个任务记计划与进度、工具调用、命令退出码、改动文件、检查点、恢复次数；任务中心一眼看全 |
| **能中断能接着做** | 暂停 / 停止 / 恢复；重启应用后未完成的任务还在，能接着往下做 |
| **改方向** | 跑到一半直接打字「别用方案 A 了，改 B」—— 它接回**同一条**任务，不重做已完成的步骤 |
| **看得见改动** | 写文件前弹窗里就能预览 Diff（默认折叠）；改完在右栏「审查」里对账 |
| **预算与刹车** | 轮数 / 工具次数 / 时长 / 重试 / token 五项上限，撞了停下来问你，不是失败 |
| **转圈检测** | 认得出 A→B→A→B 的重复执行，先改道、再交人 |
| **工具与权限** | 只读 / 需要确认 / 完全访问三档；命令按风险分级；文件访问限定工作目录 |
| **MCP** | 支持 stdio 的 MCP 服务器，外部工具和内置工具一起给模型用（环境变量白名单隔离） |
| **可观察性** | 每轮的性能时间线（首反馈 / 首字 / 整轮 / 上下文 / 模型 / 工具）、任务诊断报告 |

## 你的数据在哪

| 内容 | 位置 |
| --- | --- |
| 会话、记忆、任务台账、审计日志、改动快照 | `<应用目录>/data/` |
| 模型密钥 | 系统凭证库加密后存 `data/credentials.json`（明文只在你自己的机器内存里） |
| 除模型接口外的网络请求 | **没有**。没有遥测、没有账号、没有云同步 |

删掉 `data/` 就等于把一切清空；`data/` 整个拷走就等于搬走全部状态。

## 怎么知道它真的能跑

```bash
npm test          # 内核自检：1500+ 项，不联网、不需要 Electron
npm run test:unit # 前端单元测试：480+ 项
npm run test:app  # 无窗口跑一遍，打印主进程与渲染层的真实状态
npm run build     # tsc --noEmit + vite build（类型零容忍）
```

这套测试不是摆设 —— 开发过程中**真机发现、单测照不到**的 bug（字段名读错、相位没收尾、
长任务看不到 token）都变成了新的断言。改代码的人（包括 AI）得先让它们全绿。

## 设计上的几条硬规矩

- **单一真相源**：每个数值只在一处定义，别处只引用
- **单文件 ≤ 300 行**：超了就拆，全仓零例外
- **改了行为就得改测试**，并且用"变异测试"验一遍（把实现改坏，测试必须红）
- **盲写要声明**：没跑过的代码不许说"应该没问题"

## 已知边界

- Windows 优先（macOS / Linux 能跑开发版，但打包与托盘那部分没验过）
- 界面只有中文
- 不支持多人协作、云同步、手机端
- MCP 只实现 stdio 传输（本地服务器够用，远程 SSE 没做）
- 需要你自己准备模型 API Key（不内置、不代付）
