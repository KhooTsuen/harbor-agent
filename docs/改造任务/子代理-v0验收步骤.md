## 0. 先让「含新代码」的 Harbor 跑起来（二选一）

这台机器上现成的 Harbor 全是 `1.30.0-beta.3`，**不含** `spawn_subagent`。选一条：

### 路 A · 开发版（**不打断**你正在用的窗口）

```cmd
cd /d E:\CodexWorkbench
npm run dev
```

- 弹出一个**新的** Harbor 窗口 —— 源码直跑，含新代码。
- 它的数据目录是 `E:\CodexWorkbench\data`（**里面已有可用凭证**，能真调模型）。
- 你当前这个窗口不受影响；验完在跑 `npm run dev` 的那个黑窗口按 `Ctrl+C` 关掉。
- 本条**已实测**：2026-10-07 00:03 在这台机器上起过一次 —— vite 5273 起来、
  electron 9222 起来、日志无报错、data 指向 `E:\CodexWorkbench\data`。

### 路 B · 打包 + 更新开发版（和你平时一致）

双击 `E:\Harbor-Dev\update-to-beta4.cmd`。它会：

0. `taskkill` 所有 `Harbor.exe` —— **包括你现在读这句话的这个窗口**（预期行为）；

## 3. 逐条核判据（点哪看 → 通过长什么样）

| # | 判据 | 点哪看 | 通过 |
| --- | --- | --- | --- |
| 1 | 真机能触发 | 这条回复里的进度时间线 | 出现一行 **「派只读子代理」** |
| 2 | 父上下文只多一段结论 | 这条回复的正文 | 三份文档原文**没出现**，只有一段结论 |
| 3 | 子代理有独立台账 | `data\tasks\` 下最新两个 `.json` | 子任务那个 `parentTaskId` **非空**，`steps` 里有它自己读文件的记录 |
| 4 | 父状态机不被带跑 | 子代理跑完那一刻 | 父任务**还在继续**（拿到结论接着往下答），没被判成完成 |
| 5 | 预算从父扣 | 子任务 JSON 的 `budget.maxSteps` | ≤ 8，且 ≤ 父任务的上限 |
| 6 | 只读是硬拦 | 见下面「加练」 | 写工具调不动 |

（路 A 的 `data\tasks\` = `E:\CodexWorkbench\data\tasks\`；路 B = `E:\Harbor-Dev\dist-portable\Harbor\data\tasks\`。）

### 判据 6 的加练（可选，30 秒）

再发一句，**故意让子代理去写**：

```
用 spawn_subagent 在 data/workspace/ 下建个 x.txt，内容写 "hi"。
```

预期：文件**建不出来**（`allowWrite:false` + `permission:'readonly'` 两道闸拦住），
子代理回来的结论里会说它没有写权限，`data\workspace\x.txt` **不出现**。

## 4. 记两个数（这版真正要回答的问题）

v0 值不值得做，就看这一步：

| 数 | 从哪读 |
| --- | --- |
| 父任务 token / 上下文峰值 | 任务台账 `data\tasks\<父任务>.json` 的 `tokens`，或界面上的用量 |
| 耗时 | 同上 |

对照：**同一个问题不派子代理**再跑一次，比这两个数。
没有这两个数 = v0「隔离到底省不省」**还没验证**（任务书 §3 原话）。
