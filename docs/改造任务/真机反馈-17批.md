## 真机测试清单（给用户，按顺序点一遍）

1. **计划栏**：鼠标放在输入框正上方那条线附近、点「计划」标题上半部 —— 应该**展开计划**，不会变成拖高度。
2. **侧栏不再乱跳**：两个对话同时跑任务，看列表里的位置 —— 一轮中间不该往上升；
   跑完那一下才该浮上去。
3. **浏览器**：（a）让它读三个不同网页 —— 应该**开出三个标签**（要看得见它开过哪些）；
   （b）点另一个标签再点回来 —— 网页**不重新加载**，而且**下半屏不能变黑**（尺寸要满）；
   （c）切到别的对话 —— 标签栏里看不到上一个对话的页面；
   （d）地址栏最左的**前进 / 后退**能用，不能点时置灰；
   （e）标签栏右端的**关闭全部**只关当前对话的标签；
   （f）读页面时手动关掉那个标签 —— 应该**立刻**告诉你「页面已切换」，不是干等 45 秒。
4. **对话行**：只该有**行首那一个**状态点（已完成 / 进行中 / 需要确认）——
   上一版多加的那个闪烁点已经去掉了，行尾不该再有额外亮点。
4. **完成提醒点**：在 A 对话里发一句费时的活，切到 B 对话；A 跑完时，A 那一行应出现一个**慢闪的小点**，点开 A 后小点消失。
5. **默认对话目录**：设置 → 工具/权限里那一行 —— 显示「当前生效」，能手填、能「恢复默认」；
   新对话的文件操作应该落在 `data/chat`（老装机如果 `data/workspace` 里已有东西，会继续用它）。
6. **工具进度**：让它下载一个稍大的文件（「下载某某图到工作目录」）—— 那一行应出现
   百分比 + 进度条，跟着涨到 100%。
7. **审计分区**：设置 → 权限与安全 → 审计列表 —— 应能按**会话**折叠，会话里按**任务**分，
   同一个工具连调多次折成一行「read_file × N」，点开才是明细。
8. **应用内编辑规则**：设置 → 对话设置 → 项目规则 → 点「编辑」→ 改一行 → 保存；
   应提示已加载、**不用再点刷新**，下一轮对话就该按新规则走。
9. **上下文用量圈**：输入框下方那个小环 + 百分比；鼠标停上去应说明分母怎么来的；
   故意聊长一点 —— 过提醒线变黄、过自动线变红，并且**只压一次**（不再每轮都压）。
