## 看之前需要知道的几件事

| 文里出现的说法 | 指什么 |
| --- | --- |
| 「**任务书**」（00–04 五份） | 那次改造的任务书。**它没落盘**，只存在于对话里，所以在这里找不到 |
| 「**第 16 章**」「**第 N 节**」 | 仓库外某份私有文档的章节号（好几份，都不打算公开） |
| 「**AG-0xx**」「**Sprint 1–5**」 | 任务书里给每条待办编的号和排期，不是通用术语；提交记录里也用这个号对照 |
| 「**用户**」 | 指这个仓库的主人。那时的工作方式是人提要求、AI 执行，所以文里写的是"用户要…" |
| 「**别的会话**」 | 指之后接手这个仓库的 AI 会话 —— 项目一直是人加多个 AI 会话协作，交接靠文档 |
