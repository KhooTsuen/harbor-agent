## 1. 要做什么（一句话 + 可验证的判据）

**新增一个 `spawn_subagent` 工具**：模型调用它时，Harbor 起一个

- 只用**只读工具**（白名单硬拦，不靠提示词）、
- 有**自己的 taskId 与状态机**（不污染父任务）、
- 预算**从父任务额度里切**（不是各自一份新的）、
- **深度最多 1 层**（子代理不能再派）

的子代理；子代理跑完，**只把一段压缩后的结论**返回给父任务，子代理自己读过的文件内容
**不进父任务的上下文**。

**它的价值不是"并行干活"，是"上下文隔离"** —— 直接命中
[`../improvement-checklist.md`](../improvement-checklist.md) §2「长任务上下文断层」那条：
裁剪之后 Agent 要重新侦察一遍，根因是"没有跨轮次稳定的项目事实这一层"。
只读侦察兵让"一次性读十几份文件"这活烧在子代理身上，父任务只收结论。

### v0 的验收判据（逐条可观察）

| # | 判据 | 怎么算通过 |
| --- | --- | --- |
| 1 | 真机能触发 | 给父任务一个"要读多份文件才能答"的问题，模型主动调用 `spawn_subagent` |
| 2 | **父上下文只多一段结论** | 父任务的历史里**不出现**子代理读过的文件内容，只有子代理返回的那段 |
| 3 | 子代理有独立台账 | `data/tasks/` 里出现一条带 `parentTaskId` 的子任务，且它的 `steps` 有工具记录 |
| 4 | **父状态机不被带跑** | 子代理跑完，父任务仍是 `running`，**不是** `completed`（见第 4 节的风险点） |
| 5 | 预算从父扣 | 子代理的 token 计进父任务用量，且能单独归因（子任务自己也有数） |
| 6 | 只读是硬拦 | 子代理**调不到** `write_file` / `edit_file` / `run_shell` —— 即使提示词里让它写 |

第 4 和第 6 条是**反向锁**：它们定义的是"不能发生什么"，比正向更值钱。

## 4. 落地前必须先核的三件事（我还没读到的部分）

1. **`changeset.cjs` 的记账口径** —— 我没读这个文件。v0 只读、理论上不碰事务，
   但要确认子代理**不会意外开一个空事务**或者把改动记错地方。
2. **`task-resume.openForRun` 的并发行为** —— 同一条会话里父、子两条任务同时存在时，
   "接回旧任务"的判据会不会把子任务认成父任务的续做。
3. **`traceKey` 必须给子代理一个新的** —— `loop.cjs` 用 `traceKey = traceId || taskId` 打生命周期；
   子代理**若沿用父任务的 traceId**，它跑完那句 `life.mark('completed')` 会
   **把父任务的状态机打成终态**，之后父任务任何转移都被静默拒绝、还不发事件 ——
   这就是 AG-043 记过的那类 bug（事件 key 对不上 → 界面显示空闲、后台在跑）。
   `lifecycle.cjs` 按 taskId 分机器（已确认，是好消息），但 key 得由调用方给对。

## 5. 明确不做（v0 范围外，写清楚免得被当成漏做）

- **可写的子代理**（写进父任务的改动事务）→ 留给 v2，要先解决"跨子代理写同一文件"的串行化；
- **并行多个子代理** → v1（要先有并发上限与取消扇出）；
- **子代理再派子代理（深度 > 1）** → 不做，防 fork bomb；
- **界面显示子代理树** → v1（v0 只在任务台账里可见，控制台不画树）；
- **新增 `agent.*` 事件名 / 新增 IPC 通道** → v0 复用 `agent.tool.*`，在 payload 里带 `subagentId`；
  真要做树状显示时才动 `events.cjs` 与渲染层（那是 v1，且是另一份任务书）。

## 6. 为什么先做「只读侦察兵」（设计取舍）

- **风险面最小**：不碰改动事务、不碰并行写、不加通道 —— 只读白名单是现成的
  （`tool-scheduler.cjs` 的 `READONLY`）。
- **可证伪**：如果隔离省不下来（父上下文峰值没降），v1/v2 就不必做。这是"一次真机验证 + 两组数字"就能判的事。
- **复用了已有的可靠性零件**：工具走 `tools/index.cjs` 的咽喉（审计 / 风险 / 权限四道免费拿到），
  子任务走 `task*.cjs` 的台账，取消走 `abort.cjs`，状态走 `lifecycle.cjs`。
  **子代理缺的从来不是"再造一个循环"，是让已有的那次运行能嵌套。**

### 一条安全红线（v0 就要守住）

子代理**需要批准时，必须由父任务转发给用户本人**。绝不能"父任务批过 → 子代理自动批" ——
那等于给了模型一个**洗权限**的装置（用子代理绕过「允许本次」）。
子代理的路径授权只能是父任务的**子集**，不许变宽。
