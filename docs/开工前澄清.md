# 开工前澄清（AG-053）

> 一句话：**动手之前，把「需要你拿主意」的地方摆出来** —— 每个选项写清「因为 X，所以会有 Y 效果」
> （具体数字或事实），你答完它才开工。不想答就跳过，它自己拍板并说明理由。

## 它要解决的问题

模型最贵的错不是「不会做」，而是**不问就替你做了一个不可逆的决定**：
把包管理器换掉、把文件重写而不是改格式、顺手加了三处你没要的重构。
这些做完之后你得回头猜「它为什么这么干」。

所以这一版把「问什么」交给模型（只有它知道哪里含糊），把「怎么问」定死：
选项必须带**代价**、默认选项必须是**最容易回滚**的那个、答完才动手。

## 四套机制

| # | 机制 | 实现在哪 | 说明 |
| --- | --- | --- | --- |
| ① | **问什么** | `core/tools/ask_user.cjs` + `core/prompt-stack.cjs` 的 `CLARIFY_RULE` | 模型主动调 `ask_user`；提示词层硬要求「因为 X 所以 Y（具体数字/事实）」 |
| ② | **默认选项** | `core/clarify.cjs` 的 `normalize()` | 模型必须标一个；没标就取第一个**并记警告**（宁可让用户看到，也不整条剔除） |
| ③ | **离场超时** | `core/clarify-timeout.cjs` + `handlers/clarify-watch.cjs` | **在场不计时**（你盯着屏幕想 20 分钟是新需求在长出来）；离场才累加，到点按默认选项继续 + 发系统通知 |
| ④ | **静音** | `core/clarify-session.cjs` | 同一对话连跳 2 次就不再主动问；你说一句「先问我几个问题」当场解除 |

三条交互上的约定（都踩过才定下来的）：

- **卡片和权限条永不叠加**：澄清**让**权限 —— 权限那条 5 分钟超时算拒绝，被压在后面就是误判
  （仲裁在 `lib/clarify.ts` 的 `pickAboveInput`，不显示的那张用 `hidden` **收起而不是卸载**，
  否则你勾了一半的选项会被清空）。
- **点了才算数**：只有明确回话才当答复；关掉卡片/切走对话按「跳过」回话，不让主进程干等到超时。
- **超时 ≠ 跳过**：前者是「你没在」，后者是「你说不答」。两者带同一个 `skipped` 字段，
  所以内核里**超时优先判**（判反了模型就永远看不到 `［默认］` 标记）。

## 怎么关

设置 → **助手** → **「开工前先问清楚」**（存成 `assistant.clarifyFirst`）。
关掉 = 回到「直接开做」的老行为，也是这一条的回滚开关。

用户侧还有一次性的出口：跳过两次，本对话内它就不再问（`SKIP_LIMIT = 2`）。

## 四个值（唯一真相源：`core/clarify-config.cjs`）

| 键 | 默认 | 夹取范围 | 含义 |
| --- | --- | --- | --- |
| `clarifyFirst` | `true` | 只有 `false` 才算关 | 开工前要不要先问 |
| `clarifyIdleSeconds` | `30` | 5 – 600 | 多久没键鼠活动算「人不在」——在这以内**不计时** |
| `clarifyTimeoutMs` | `600000` | 1000 – 3600000 | 离场后等多久自动采纳默认（10 分钟） |
| `clarifyMaxWaitMs` | `1800000` | 60000 – 7200000 | 同一任务累计离场等待上限：超了本任务**不再弹卡**，用户回来看一次总结 |

⚠️ 改这些值只需要改**那一个文件**：默认值、夹取规则、以及「设置改完下一跳生效」
（巡查器每跳现读）都从它出。别在调用方再翻译一层键名 —— 批③ 就是因为
「调用方给 `timeoutMs`、巡查器读 `clarifyTimeoutMs`」静默退回了默认值，真机才现形。

## 边界（照实写）

- **定时任务 = 无人值守**：不弹卡、**不挂请求**、直接按默认选项开工，
  并把「采纳了什么」写进工具结果（就是留痕）。语义和隔壁 `confirm: async () => false` 同源：
  没人在场 = 没人能决定。⚠️ 定时任务那条会话在界面上**没有只读卡**
  （那一轮没有渲染层参与），要看得去会话记录里翻工具结果。
- **超时通知是无条件发的**（不像任务结束通知要看窗口在不在前台）——
  超时本身就意味着人不在，这正是要通知他的时候。标题带任务名，正文写清替他定了什么，
  点一下跳回那条对话。
- **只读卡**：答完/超时后那一轮最上面会留一张只读卡（问题 + 你选了哪个 + 你补的话）。
  没人点头的那两种情况标 `（默认）` 并说清是「你当时不在」还是「定时任务」，
  **不许说成「（已选）」**。老对话没有这个字段，渲染一字不变。

## 踩过的坑（都在这条链路上）

- **事件没走对话 emitter** → 少了 `chat:event` 频道和 `requestId`，渲染层按 requestId 过滤直接丢，
  卡片永远不出现，而 tsc / lint / 单测 / 自检全绿。
- **`render()` 先判 `skipped`** → 离场被当成「用户说跳过」，`［默认］` 永远不出现。
- **跨模块约定两边各写一套**（键名 / 字段名 / 回调没人接）→ 一天之内栽了四次，
  已经写成 `AGENT.md` **硬约束 #9**，并加了 `npm run lint:kernel`（内核 `.cjs` 的未定义标识符）。
