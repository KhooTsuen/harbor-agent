## 6. 阶段报告（固定格式，一次性汇总）

- **结论**：token 优化实施完成、全链验证通过（自检 2723/0、vitest 94、test:app 全过）；收益集中在**冷/大前缀场景**（P95 −41.2%、cache turn2 −82.4%、T7 −59.7%、三组每 run −13.1%）；稳态长对话与部分小任务有 +3~9% 上浮（如实）；预热未达阈值；模板守卫缺陷（TOK-P2-004）已修复但早于电池快照。
- **测试数量**：基线 42 run / 优化 51 run（suite 24×2、cache 3×2、compact 15 vs 24）；预热实测 1 实例；全链验证 1 次。
- **P0-P3**：0 / 0 / 5 / 4（详见问题文档）。
- **重启统计**：5 次启动、4 次关闭→重开、故障性 0；与规范「≤3」字面不符（超 1 次，预热冷启动前提）。
- **基线 token → 当前 token**：suite 443,964 → 408,956（−7.9%）；P95 42,229 → 24,822（−41.2%）；三组合计每 run 14,820 → 12,880（−13.1%）。
- **缓存命中率**：suite 中位 76.7% → 82.2%（+5.5pt）；均值 77.1% → 76.9%；240/240 行可计算；不伪造 0。
- **质量对比**：suite 24/24 vs 24/24；compact 24/24 vs 14/15；产物判据与安全边界全过，无回退。
- **成本口径**：仅统计 API 原始 usage（prompt/completion/cache hit/miss）；命中部分按服务商折扣计价（未折算价格）；两次电池合计约 1.28M tokens（另有预热实测 ~6k in）。
- **证据路径**：`tmp/tok/baseline.jsonl` / `optimized.jsonl` / 两份 *-summary.json / `compare.json` / `per-task.json` / `evidence.json` / `approvals.jsonl` / `tmp/tok/Harbor/data/cache/prompt-diag/` / `tmp/tok/Harbor/data/logs/token-metrics.jsonl`。
- **待确认**：① 是否发布 beta.18（tag/便携包/更新 `E:\Harbor`）；② 预热改进方向（带会话低频层再测 or 维持默认关）；③ compact 稳态 +2.9% 是否立项专项定位；④ 规范「重启 ≤3」超 1 次是否接受（原因见 §1）。
