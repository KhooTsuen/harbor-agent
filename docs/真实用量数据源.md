# 真实用量：数据源与查询入口（第 6 项第一阶段）

> 这一版**只做采集与持久化**，统计界面留给后续设置工作区阶段。
> 本文是那一阶段的接口约定 —— 别在界面里另起一套口径。

## 数据落在哪

`data/logs/token-metrics.jsonl`：**一行 = 一次真实的模型调用尝试**。
只记数字与标识，不记任何消息内容。文件超 6MB 自动轮转一份 `.1`（有界）。

## 一行里有什么

| 字段 | 含义 |
|---|---|
| `at` | 毫秒时间戳（可按天聚合） |
| `entry` | `api` / `cli` —— 走的是 HTTP 还是本机 Codex CLI |
| `providerId` / `model` | **实际执行的那一家**（降级时记的是最终那家；失败的行记失败那家） |
| `sessionId` / `taskId` / `trace` | 会话 / 任务台账 / 运行实例，三个都记、互不替代 |
| `outcome` | `ok` / `failed` / `aborted` |
| **`known`** | **这行的 token 数字可不可信**（下方最重要） |
| `prompt` / `completion` / `total` | 上游报的数字；`known=false` 时是 `null` |
| `reasoning` | 思考 token（属于 completion，不额外加） |
| `cacheHit` / `cacheMiss` / `cacheSource` / `hitRate` | 缓存读取，按各家真实字段；缺就 `null` |
| `cost` / `costSource` | **只有服务商真给金额才有值**，否则 `null` + `unavailable` |
| `retryIndex` | 第几次尝试（0 = 首次） |
| `missing` | 没拿到用量的原因（事后可诊断） |
| `ttftMs` / `latencyMs` | 首字延迟 / 总耗时 |

## 三条铁律（界面必须照它显示）

1. **`known=false` 不许显示成 0**。显示「未知」或「等待统计」——
   0 是「服务商确认这次消耗为 0」，两件事不能混。
2. **费用没有就是不显示**。`cost=null` 时写「未提供」，不许拿本地价目表算一个数说成实际花费
   （定价表算的叫「预估」，与真实账单是两回事）。
3. **`legacy` 单独标**。本轮之前写的老记录没有 `known` 字段，`summarize` 会把它们计入
   `legacy` 数 —— 新旧口径的累计不要合并后标成「实际消耗」。

## 查询入口

内核函数（唯一实现，界面只能调它，不要自己算）：

```js
const metrics = require('electron/core/token-metrics.cjs')

metrics.summarize()                    // 全部
metrics.summarize({ sinceMs })         // 某时间点之后
metrics.summarize({ entry: 'cli' })    // 只 CLI
metrics.summarize({ kind: 'llm' })
```

返回形状（节选）：

```js
{
  requests, known, unknown, legacy,   // 三类分开数
  prompt, completion, total,          // 只累计 known 的行
  reasoning, reasoningUnavailable,
  cacheHit, cacheMiss, rateable, hitRate,
  cost, costUnavailable,              // 一行都没给金额时 cost 是 null
  errors, aborted, retries,
  byProvider: { [providerId]: { requests, known, unknown, prompt, completion, total } },
  byEntry:    { api: {...}, cli: {...} },
}
```

## 明确不做的事

- 不把上下文估算（`context-builder` 的 `estimates`）放进这本账 —— 它只服务裁剪与预算。
- 不在两处各记一份：记账点只有 `loop-model.cjs` 一处（那里才知道「第几次、发给谁」）。
- 不为了统一而抹平各家差异：CLI 不报的指标就是 `null`，不拿 API 的字段硬填。
