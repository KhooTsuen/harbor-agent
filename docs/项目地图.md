## 怎么刷新（数字会漂，以命令输出为准）

在仓库根目录跑；**这些输出才是真相源，本文只是某天的快照**：

```cmd
git rev-list --count HEAD              :: 提交数
git tag                                :: 发布 tag
git ls-files | find /c /v ""           :: 项目文件数（只算被 git 跟踪的）
npm test                               :: 内核自检 —— 看末尾「通过 N 项」
npm run test:app                       :: IPC 通道 —— 看 channelsExpected
```

文件数 / 行数 / 各目录分布（一条 node 命令，跑在 Windows cmd 里）：

```cmd
node -e "const{execSync}=require('child_process');const fs=require('fs');const f=execSync('git ls-files',{encoding:'utf8'}).split('\n').filter(Boolean);let l=0;for(const x of f){try{l+=fs.readFileSync(x,'utf8').split('\n').length}catch{}}console.log(f.length,'files /',l,'lines')"
```

（想看某个子目录的明细，把它和 `git ls-files` 组合；需要一张自动生成的图时，
可以给仓库加一个只读的 `scripts/project-map.mjs`，把上面这段固化下来。）
