### 踩坑（都白跑了一轮，记下来省下次）

1. `tmp/night-cleanup.cjs` 按命令行匹配 `night-p02`，**也会匹配到调用它的那个进程自己**
   → 启动即自杀，日志被截空后再没写过一行（看着像「脚本根本没启动」）。现在传 `HARBOR_KEEP_PID` 豁免。
2. 写在模板字符串里的 **`.find()` / 正则** 全是坑：
   - `function(x){ 表达式 }` **漏了 return** → 判据恒 undefined → 永远「点不到按钮」；
   - 模板字符串里的 `\n` 会被解释成真换行 → 塞进页面就成了 `/ <换行> /g` → `SyntaxError: missing /`；
   - 注释里带**反引号**会提前截断模板（踩了两次）。
   现在统一：`filter(...)[0]` + 显式 `return` + `String.fromCharCode(10)` + 注释不写反引号。
3. 跑完 `main()` 但假模型 server 没关 → node 不退出 → 端口不放、**启动它的终端被占死**
   （后面两次重跑「没有任何输出」就是这么来的）。现在跑完 `server.close()` + 显式 `process.exit`。
4. 真机脚本里的开关**别用环境变量**：要穿过 PowerShell + cmd 两层，`set X=1 && node …`
   实测传不进去（白跑两轮）。改成命令行参数（`--plan` / `--slow=26000`）。
