## 三、四组改动 · 用户视角的「改前 → 改后」

### ① 安全可见性（A1 + A2）

| | 改前 | 改后（真机实测） |
|---|---|---|
| 右栏「错误」标签 | 只有文字，**没有任何未读提示** | `错误（1 条未读的严重错误）` |
| 右栏**折叠 / 窗口窄**时 | 严重错误**彻底看不见** | 顶栏「切换右侧面板」也带**同一个**信号：`切换右侧面板（1 条未读的严重错误）` |
| 打开错误面板 | 容易被当成「问题已处理」 | 面板写明：**打开只清「未读」，错误本身不消失、不被标记为已处理** |

⚠️ **未读 ≠ 未解决** —— 这是本轮最在意的一条：角标表达的只是「自你上次看过之后新出现的严重错误」，
点开只推进「已读线」，不动错误数据、不做任何「已处理」标记。真机验证时，点开后标签回到 `错误`，
**面板里那条 P0 仍然列着**。

另外：本轮**没有引入轮询**（内核没有「有新错误」的推送事件，加推送=改 IPC 契约）。
角标按语义事件触发：应用启动 / 窗口重新可见 / 窗口获得焦点 / 一轮跑完。

### ② 成果与文件修改的关系（B3）

Phase 0 实测发现：Agent **写文件成功**，右栏「成果」却是 `0`（文件其实进了「审查」）。
根因：**「成果」和「工作区改动」本来就是两条数据源**（前者 = 内核登记的正式产物，后者 = 本轮文件改动）。

改后：成果面板空态不再只说「完成带文件名的代码块后…」，而是讲清定位 ——
**「成果只放正式产出：带文件名的代码块、内核登记的产物。普通的文件修改不算成果。」**
并且在**确实有改动**时直接给一个按钮：**「去『审查』看本次修改的 N 个文件」**。

> 边界：**没有**把普通文件修改自动标成「成果 / 已验证产物」—— 两条数据源保持分开。

### ③ 任务进度语义（B1 + B2）

问题：「任务步骤 N/M」数的是**模型写的计划**里打了 `[x]` 的条数，读起来却像执行进度。

| | 改前 | 改后（真机实测） |
|---|---|---|
| 任务行 | `已完成 · 1/2 步` / `1/2 步` | `已完成 · **计划** 1/2 步` |
| 计划卡 | `执行计划 · 1/2 步` | `**计划** 1/2 步` |
| 进度时间线 | 计划待办与执行行混在一段 | 分成两段：**`执行进度`**（真实相位 + 工具行）与 **`计划（模型给的 · 未执行）`** |
| 百分比 | —— | **全仓库没有任何任务百分比**（新增测试守着） |

> 边界：**没有**通过读模型自然语言去猜执行进度；**没有**改任务台账/协议；措辞的真相源收敛到一处
>（`planProgressLabel()`），三个页面共用。

### ④ 状态栏术语统一（D）

| | 改前 | 改后 |
|---|---|---|
| 状态栏 | `… pair deepseek-flash high …`（内核字段原值） | `… **标准** deepseek-flash **高** …` |

复用已有常量（`modeMeta().label`、`REASONING_LABEL`），**没有新建第二份映射**。

## 五、真机才抓到的两个坑（值得单记）

1. **`ErrorEntry.lastSeen` 类型声明是 `number`，真实数据却是 ISO 字符串** ——
   字符串和数字比大小**恒为 false**，于是角标**永远不亮**，而**单测全绿**（测试夹具用的是数字）。
   已在展示层做两种形状兼容 + 补回归用例；**类型/内核侧没动**（列入待批）。
2. **错误观察哨是「攒着 + 15 秒定时落盘」** —— 刚发生的错误十几秒后才写盘，所以角标是
   **在下一个触发点亮**，不是「瞬间」亮。这**不是展示层能解决的**（要内核在一轮结束时 flush）。

## 七、还没解决的（如实）

1. **`lastSeen` 类型裂缝**（§五·1）—— 展示层已兼容，但「类型 vs 真实数据」两个口径仍不一致，需你定「哪个是标准」。
2. **角标有 15 秒级时延**（§五·2）—— 要内核在一轮结束时 flush 才能真正「即时」。
3. **未验证项（明确标 `NOT_TESTED`，不冒充全验）**：
   - 策略拒绝 vs 普通故障的区分（需改事件契约 → 禁改项，未做）
   - 暂停 / 继续（pause/resume）本轮未单独复测
   - 窄窗口下标签栏被裁切的行为：只做了推理，未单独截图实测
4. 真机对照用的是**假上游**：证明的是「内核记录 → error:list → store → 角标」这条**真实链路**，
   不代表真实上游的行为。
5. **改动未提交**，停在 working tree。
