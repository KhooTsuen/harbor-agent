### 1.3 三层体系的**实际状态**：三处数值对不上

设计声明（`src/constants/design.ts:104-114`）与 CSS 变量（`src/index.css:115-118`）**各写一套，然后漂了**：

| 层 | `design.ts` 声明 | `index.css` 实际 | tailwind class |
|---|---|---|---|
| meta | **14px**（`FONT_SIZE.meta.size = 14`） | **15px**（`--text-meta: 0.9375rem`） | `text-meta` = 15px |
| body | 16px | 16px ✅ | `text-body` = 16px |
| title | 24px | 24px ✅ | `text-title` = 24px |
| dense（「唯一例外」） | **13px**（`FONT_SIZE_DENSE = 13`） | **14px**（`--text-dense: 0.875rem`） | `text-dense` = 14px |

**结论**：
- **meta 声明 14、实际 15**（tailwind 的 `text-base` 也是 15px，两个名字同值）；
- **dense 声明 13、实际 14**（而 `text-xs` 才是 13px —— 名字和值**错位**了）；
- `index.css:471` 把 `body` 的字号设成 `var(--text-meta)` = **15px**，与「正文 16px」的声明不符 —— 印证 `src/lib/utils.ts:8` 注释里那句「实际渲染 15px 继承值」。

**这就是噪声审计里「15px 39 处未在 token 中声明」的真身**：15px 就是 `--text-meta`。

## 二、窄窗口与缩放回归（UX-10）

### 2.1 实测方法与**一处必须说明的局限**

- 用具 **`tmp/p4-probe.mjs`** / `tmp/p4-narrow2.mjs`：起**隔离便携副本**（不碰你的实例），CDP 连上后改窗口/视口，用 DOM 探针取几何数值 + 截图。
- ⚠️ **`Browser.setWindowBounds` 在本版 Electron 上不可用** → 全部退回 `Emulation.setDeviceMetricsOverride`（`tmp/p4-narrow2.mjs` 里打印了 `Emulation(仅视口)`）。
  **所以：改的是「视口」，不是「真窗口」。** CSS 布局只看视口宽度，因此**三栏表现是实测的**；但**真窗口被拖到 320px 时的物理表现（原生标题栏、窗口圆角、任务栏交互）为 `NOT_TESTED`**。
- ⚠️ **150% 缩放**：应用设置存在 localStorage（`personal-agent:settings`），但**改它无效** —— 真机实测「写入 `fontScale:150` → reload 后被写回 `100`」（设置的主真相不只在 localStorage）。改用 `useApplyAppearance.ts:63` 的**同一机制**：直接写根字号 `document.documentElement.style.fontSize = '24px'`（16 × 150%），实测稳定保持。**这是等效机制，不是系统 DPI 150%**（系统 DPI 缩放仍为 `NOT_TESTED`，见 §3.2）。

### 2.3 结论：三个真问题

1. **320px 下主区被压到 0**：侧栏 `240px` + 右栏 `360px` 都是**固定 px**，合计 600 > 320 → `main` 宽度 = **0**，输入框只剩 **28px**（一个汉字的宽度），文档出现**横向溢出**。三栏布局在 320px 下**不可用**。
2. **150% 缩放在「正常宽度」下也会溢出**：E 场景（1400×900）右栏仍是固定 `360px`，但标签栏内容全用 **rem**（随根字号 ×1.5）→ **「错误」标签被挤出视口**（8/8 → 7/8），文档横向溢出变 `true`。**100% 时标签栏是 359/359，零余量**（第一次实测）—— 任何放大都会溢出。
3. **弹窗不偏移** ✅：320×700 与 320×400 下弹窗都在视口内（`l=24, r=296`，居中于视口），`offscreen = false`。**这条通过**，无需改。

### 2.4 建议（供拍板）

| 问题 | 可选做法 | 归属 |
|---|---|---|
| 320px 主区归零 | **(a)** 设**应用最小窗口宽度**（如 720px），低于此不允许再缩 | ⚠️ 主进程 `setMinimumSize` → **属 Runtime，需单独报批** |

| | **(c)** 不做，标为「已知边界：右栏需 ≥ 某宽度」 | ✅ 零改动 |
| 150% 下右栏溢出 | **(d)** 右栏宽度**随根字号缩放**（`360 × fontScale/100`） | ✅ 纯展示层 |
