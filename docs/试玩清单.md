# 试玩清单（2026-09-20 · 版本 1.1.2）

> 给开发者自己试用的清单。**照着点就行**，每题都写了「应该看到什么」和「不对的话八成是哪坏了」。
>
> ## 开工前的两件事
>
> 1. **用哪个包**：`dist-portable/PersonalAgent/PersonalAgent.exe` 已经是最新的
>    （含本轮修的三个 bug）。如果你想跑开发模式 `npm run dev` 也行，效果一样。
> 2. **建议设置**：工具权限设成 **「需要确认」**（设置 → 权限与安全 → 工具权限），
>    这样能看到权限弹窗和 Diff 预览。工作目录建议**新建一个空目录**（放三个假文件：
>    `README.md` / `build.sh` / `tests.py`），让 Agent 折腾它，别拿自己的真项目试。
>
> ## 三条约定
>
> - 每题「**看什么**」都写得很具体；**没看到就是没过**，别替我找理由。
> - 有问题就把这三样发我：① 现象截图 ② 任务中心里那条任务的 **诊断 → 复制全文** ③ 有报错就原样复制。
> - 忙的话**只做 A 组（10 分钟）**，那是最值钱的。

## A 组 · 10 分钟（本轮新功能，最该先看）

### A1 控制台：任务跑到一半时看得见八项

1. 新建对话，工作目录设成 `tmp/real-ws`
2. 发一句**要好几步**的话，比如：
   > 先列个计划：读 tmp/real-ws/README.md 和 build.sh，对比两边的构建步骤，然后跑 python tests.py，最后给结论。
3. **还在跑的时候**（看到输入框旁是「暂停/停止」按钮），点右栏 **任务** → 那条任务的 **详情** → **控制台**

**应该看到**：八行 —— 状态「进行中」、当前步骤是**计划里的一条**（比如「读 README.md」这类短句）、运行时间在走、Tool Calls 有数字、Retry「0 次」、权限「询问」、模型名、**Token 是个数字（14K 这种）**。下面六个按钮：暂停 / 停止 / 查看 Diff / 查看 Tool / 调整权限。

**不对的话**：
- Token 显示 `—` → 「用量没记上」（就是这轮修的 bug ①，说明这个包是旧的）
- 当前步骤是一大段**文件内容** → 修好的 bug ③ 又回来了
- 少几行 / 少按钮 → 告诉我少了哪个

### A2 停下来之后，还能直接打字（这轮修的 bug ②）

接着 A1：

1. 点控制台里的 **暂停**（或等它自己停下来 —— 撞预算、或转圈被拦都会停）
2. 停下后看**输入框那一边**

**应该看到**：输入框右边变回 **「发送」**（一个向上箭头），**不是**「停止生成 / 暂停生成」。任务行里会出现「继续 / 停止 / 调整预算/放弃」这些。

**不对的话**：任务明明停了、输入框还显示「停止生成」→ 相位没收尾，是 bug ② 复发，告诉我。

### A3 改方向：别做 A 了，改 B（本轮新功能）

1. 接 A2（任务停在「已暂停」状态），**不要点「继续」**，直接在输入框打一句新方向：
   > 改一下方向：别管 build.sh 了，只把 README 的安装那一节说清楚。
2. 发出去，等它停下
3. 看右栏 **任务** 里**有几条任务**，再看那条任务的 **详情**

**应该看到**：
- 任务**还是 1 条**（不是两条！）—— 这是关键
- 详情里出现 **「你改过方向 · 1」**，下面列着**你刚打的那句原话**
- 计划那里如果它重新规划了，会多一个版本，理由写着「**按你的改动重新规划**」

**不对的话**：
- 变成两条任务 → 没接回原任务（这一轮的修复没生效）
- 没有「你改过方向」 → 用户那句没记进台账

### A4 Token 是真数字，不是摆设

在 A1 那条任务跑完之后，再看一次控制台的 Token。

**应该看到**：数字比跑动中**更大**（或者至少不是 0 / `—`）。用「日志」面板（Ctrl+J）里那条命令的用量也对得上。

**不对的话**：跑完还是 `—` → 告诉我你用的哪个模型（有些第三方站点不返回用量，那是兼容性问题，不是 bug）

## B 组 · 核心流程（15 分钟，做完更放心）

### B1 「下一步」建议

让 Agent 改一个文件（比如「把 README 的标题改一下」），等它**成功结束**。

**应该看到**：输入框上方冒出一排建议按钮，比如「运行测试 / 查看 Diff / 提交修改 / 继续优化」。**点一下只是把话填进输入框**（不会自己跑起来）；「查看 Diff」是切右栏。

### B2 Diff（改了什么，一眼看到）

1. 接 B1，点 **查看 Diff**
2. 右栏切到 **审查** 标签

**应该看到**：改动的文件名 + `+N −M` 的统计 + 逐行的绿/红差异；**顶栏右上**也有一个 `+N −M`，数字应该跟这里一致。

### B3 权限弹窗里的 Diff（默认折叠）

让 Agent 改一个文件，权限弹窗出现时看它。

**应该看到**：弹窗**默认是收着**的 —— 只有一行「会改 1 个文件 +1 −1」+ 一个「查看 Diff」；点开才展开具体改了哪几行。**取消 = 拒绝**（关掉弹窗也算拒绝，不会偷偷执行）。

### B4 AI 撞上预算时

设置 → 对话（或任务自己）把 **轮数上限** 调成很小的值（比如 2），然后让它做一件需要很多步的事。

**应该看到**：任务行给出「继续 / 停止 / 调整预算」，并说清「到了哪个上限、用了多少（比如 2 / 2）」。点「继续」能接着做。

**不该看到**：任务被标成「失败」（撞预算不是失败，是等你拍板）。

### B5 停止 vs 暂停，是两件事

- **暂停**：做完手上这一步才停，之后能「继续」
- **停止**：立刻断，正在跑的命令会被杀掉

各试一次，看按钮名字和结果是否对得上（暂停后任务应在「已暂停」、点继续能接上；停止后这一轮就结束了，已经产出的内容留在对话里）。

### B6 Tool 日志与「查看 Tool」

在控制台点 **查看 Tool**。

**应该看到**：底部面板打开，切到 **日志** 那一栏，是一张全局的工具流水（时间 / 工具 / 状态 / 耗时），**可以搜索**。

## C 组 · 只有你能判断的两项（第 16 章验收里「需要眼睛」的）

### C1 UI 真的不冻吗

发一个**长活**（比如「对比 README 和 build.sh，再跑 python tests.py」），在它跑的时候：

- 用鼠标滚对话历史（应该顺滑）
- 在输入框里打字（应该一个字都不卡）
- 切到另一个对话再切回来（内容应该还在，**不该**变成空白或重新加载）

**不对的话**：卡顿、掉字、白屏 —— 把当时在做什么、大概几秒告诉我。

### C2 通知会不会抢走焦点

（这条只能你判断）

1. 让一个任务跑着，把窗口**最小化**（或切到别的软件）
2. 等任务完成
3. 看系统通知弹出时：**你的输入焦点有没有被抢走**（比如正在别的软件里打字，字是否还进到原来那个窗口）

**应该看到**：通知出来但**不抢焦点**，任务栏图标不闪。

### C3 状态词是不是一套话

同一个任务，看三个地方说的是不是一致：

- 任务行 / 任务中心的状态（进行中 / 已暂停 / 等你确认 / 已完成…）
- 状态栏（窗口最下面那条）
- 控制台里的「状态」那一行

**应该看到**：三处的用词是同一套（不会有地方说「执行中」、另一处说「运行中」）。颜色也应该是同一套语义色。

## D 组 · 有空再看（边界）

- **D1 后台/前台不串**：开两个对话同时跑任务，切来切去，看进度各归各的、不互相覆盖。
- **D2 任务诊断**：任一任务 → 详情 → **诊断** → 「复制全文」，读一遍 —— 它应该只写台账里真有的东西（状态、用时、模型、计划进度、失败步骤、改动文件、命令退出码、授权次数、检查点、恢复次数），**不猜**。
- **D3 陈旧任务清理**：放一条「已暂停」的任务不管，重启应用，看它还在不在、能不能继续。
