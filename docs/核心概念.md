# 核心概念

> 一页讲清 Harbor 里那几个词。想先跑起来看 [README 的快速开始](../README.md#快速开始)；
> 想看代码怎么组织看 [`架构.md`](架构.md)；想看安全边界看 [`安全模型.md`](安全模型.md)。

## 它们怎么套在一起

```
会话（对话）
└── 任务（一件活）              ← 一等对象：有自己的名字与台账，跟聊天分开存
    └── 运行（你发一次消息）     ← 一次「你说一句 → 它做完停下」
        ├── 回合（调一次模型）
        │   └── 工具调用（读文件 / 跑命令 / 写文件 …）
        └── 改动事务（这次改了哪些文件 —— 可整批撤）
```

---

## 会话（对话）

**是什么**：聊天记录，加上**这条对话自己的设置**：回答深度、权限覆盖（联网 / 工具 / 写文件）、
钉住的技能、温度。

**存在哪**：`data/sessions/<id>.jsonl`，一行一条消息。

**界面上**：左侧栏。可以归档、重命名、删除；按工作目录分到「对话文件夹」里。

**容易误会**：
- 删对话**不会**删掉它产生过的任务 —— 任务单独存在 `data/tasks/`；
- 对话的设置在**对话级**，改了不会污染别的对话（想改全局去设置里改）。

## 任务

**是什么**：一件活的台账。记着：名字、目标、计划与进度、每一次工具调用、跑过的命令与退出码、
改过哪些文件、检查点、恢复过几次、**停下来时是为什么**。

**存在哪**：`data/tasks/<id>.json`，一个任务一个文件（坏一个只坏一个）。

**界面上**：右栏「任务」。

**它什么时候出现**：你说一句需要动手的话，第一轮就会立一条。之后说「继续」是**接回同一条**，
不是新建 —— 不然「不重复已完成步骤」就无从谈起。

**状态**（六种）：`running` 在跑 · `waiting_user` 等你确认 · `paused` 停住了（**可以接着做**）·
`completed` 做完了 · `failed` 失败了 · `cancelled` 被放弃。

> **`paused` 不是失败。** 撞上预算、检测到转圈、你按了暂停、应用被关掉 —— 都会停在 `paused`，
> 而且**能接着往下做**。

## 计划与步骤

**是什么**：模型在你第一句话之后给出的一个 ```plan 块 —— 第一行是任务名，下面每行一条步骤；
每做完一步，它把那条标成 `[x]` 并重发整份。

**界面上**：任务横幅的 `N/M 步`、右栏的勾选列表、控制台的每一步。

**边界**：计划是**模型定的、可改的**。你中途改方向、或者它发现路走不通，都会重排 ——
历史版本留着（`planVersions`），不会丢。

## 检查点

**是什么**：任务走到关键节点时打的一个点：标签、备注、当时涉及的文件与命令。

**用途**：配合**回退**用 —— 「回到这一步之前」撤的是**这次任务改动过、且在这个点之后**的那部分
文件改动。判据是时间戳，不是「把磁盘倒带」。

**边界**：它只认**自己在改动事务里记过**的文件；你手动改的、别的工具改的不在其中。

## 改动事务（changeset）

**是什么**：一次运行一个事务 —— 写文件**之前**先留快照，改了什么、怎么撤都记着。

**界面上**：右栏「审查」逐文件看 Diff；顶栏 `+N −M`；对话区的「撤销这些改动」是**整批撤**。

**两条规矩**：
- **写操作不会自动重试** —— 怕把写坏的东西再写一遍（读操作会重试）。
- 改动**先弹窗给你看**再落盘（Diff 默认折叠，展开看细节）。

## 工具调用

**是什么**：它每一次动手 —— 读文件、搜代码、跑命令、写文件、开网页、生图……
每次一条记录：工具名、成败、耗时、摘要。

**界面上**：对话里的工具块（默认折叠）+ 右栏控制台的 Tool Calls。

**哪些要点头**：
- **写文件** → Diff 确认弹窗；
- **跑命令** → 按风险分级，高的弹确认，critical（格式化、提权、递归删、关杀软…）**一律拦**；
- **联网** → 按网络策略（`allow` 直接放 / `ask` 问你 / `deny` 拦下）；
- **浏览器里填密码框** → 单独确认。

被拒绝时它**不会反复重试**同一个操作，会换个思路或者来问你。

## 权限

三层，各管一件事：

| 层 | 管什么 | 在哪儿设 |
| --- | --- | --- |
| 命令风险分级 | 这条命令危不危险（low / mid / high / critical） | 内建，critical 不可越过 |
| 文件范围 | 只能碰工作目录，出圈要你批（本次会话有效） | 状态栏的工作目录 + 授权弹窗 |
| 网络策略 | 能不能联网、连哪些主机 | 设置 → 安全 |

完整设计（含「管不到什么」）见 [`安全模型.md`](安全模型.md)。

## 记忆

**是什么**：结构化条目（偏好 / 事实 / 决定…），按 范围 · 类型 · 重要度 · 新鲜度 · 相关性 打分，
**只挑前 N 条**注入，不是整篇塞。

**界面上**：设置 → 记忆。「为什么是它」面板会把**上一轮注入了哪几条、各多少分**摆出来。

**两条规矩**：默认**不自动写**（记错一条比改错一个文件影响更久）；项目级与全局分开。

## 技能

**是什么**：放在 `data/skills/` 的说明文档（可带 `permissions` 声明），教它某类活该怎么干。

**平时**：只是系统提示里的一份**清单**（名字 + 用途 + 路径），正文由模型按需去读。

**钉选**（对话设置 → 技能）：钉住之后，正文进系统提示，而且它 `permissions.network` 里的
声明**由内核强制执行** —— 说 `deny` 就是 `deny`，哪怕全局是 `allow`。
（`file` / `shell` 两档**仍然只是声明**，界面里写明了。）

## 项目

**是什么**：按工作目录归拢的登记项，有自己的名字、颜色、置顶、归档。

**存在哪**：`data/projects.json`。

**容易误会**：**「移除项目」不删任何数据** —— 它只是从侧栏拿掉，那些对话和任务一条不少
（会落到「未归类」下面）；再在那个目录里新建对话，项目自己会回来。

## 预算与刹车

**是什么**：每个任务的五项上限 —— 轮数 / 工具调用次数 / 运行时长 / 重试 / 本任务 token。

**撞上会怎样**：**停下来等你**（任务标 `paused`），三个选择：**继续 / 停止 / 调整预算**。

**转圈检测**：认得出 A→B→A→B 这种原地打转 —— 先改道（让它换个法子），连着几次不听才交给你。
它不把话说死：提示里是「**可能**陷入重复执行」。

---

## 一轮里到底发生了什么

1. 你按下发送 → **本地先占位**（不等后端，立刻有反馈）
2. 装配这一轮的系统提示（环境 / 工具 / 技能 / 记忆 / 项目说明 / 任务状态）→ 调模型
   （失败会重试，还能换一个供应商，并明确告诉你）
3. 模型要工具 → 该确认的弹确认 → 执行 → 结果喂回去 → 再调模型（**回合**循环）
4. 每一步都记台账；碰到边界（预算 / 转圈 / 你按停）就**停在可恢复的地方**
5. 结束：结论 + 改动对账 + 下一步建议（有测试的话，明确说清过没过）

每一步的耗时（首反馈 / 首字 / 整轮 / 上下文 / 模型 / 工具）都在右栏「状态 → 性能」里。
