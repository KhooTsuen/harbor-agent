# 更新历史（Release 归档）

> 这个文件解决一件事：**GitHub 上删掉的 release，更新内容去哪查**。
> 每个版本的完整正文（为什么改 / 改了什么 / 验证数字 / 遗留）一律在
> [`CHANGELOG.md`](../CHANGELOG.md) —— 共 187 个版本段，最早到 `0.2.0`。
> 本表只是**索引**：版本、发布日期、状态、一句话、「去 CHANGELOG 搜哪个标题」。
>
> **保留策略**：GitHub 上只保留 **1 个 beta + 1 个正式版**（规矩见 [`发布检查.md`](发布检查.md)）。
> 删除的是「版本入口 + 构建 zip」；**代码提交都还在 git 历史里**。
> 权威清单（tag → commit SHA → 一句话）：`tmp/releases-manifest-all.json`，
> 需要旧版本号可 `git tag <版本> <SHA> && git push origin <版本>` 回建标签（zip 无法恢复）。
