## 二、在 Harbor 里干活前的三步设置（点一下就好）

`E:\Harbor` 现在还是「刚装上」的默认配置，要让它能改这个仓库，需要：

1. **工作目录** = `E:\CodexWorkbench`（设置 → 通用 → 工作目录）。
   这样每轮对话会自动注入仓库里的 `AGENT.md`（见 `electron/core/project.cjs`）。
2. **Shell 超时** 从默认 60 秒调到 **300 秒以上**（设置 → 工具）。
   否则 `npm run verify`（约 2–3 分钟）和 `npm run package`（发版打包）会被提前撚断。
3. **文件范围**：确认是「已授权 / 工作目录」（默认 `fileScope: granted` + `permission: full` 就够改仓库）。

三处都能在设置页改，改完**不用重启**。

## 五、干活要用的工具（都在仓库里）

> **规矩（2026-10-06 起）**：反复要跑的事，**工具进仓库、有名字**（`package.json` 的 `scripts`）。
> 一次性脚本别再往文档里写 —— `tmp/` 有卫生检查（条数 / 体积超限会被清），写进文档就会失效。

| 命令 | 干什么 |
| --- | --- |
| `npm run verify` | 全链：typecheck → lint → lint:kernel → 格式 → 行数 → check:rules → test:rules → 单测 → 自检 → 构建 |
| `npm run preflight` | 一站式收工（`verify` + 应用自检 + 打印「剩下必须人做的」） |
| `npm test` | 内核自检（改 `electron/**/*.cjs` **必跑**，`.cjs` 不过 tsc） |
| `npm run test:app` | 应用自检：看 `channelsExpected` / `channelsMissing` |
| `npm run check:lines` | 单文件 ≤ 300 行红线（**含注释**，权威口径） |
| `npm run check:lines:code` | 同一条线但**不算注释**（诊断：贴线时看代码占多少，决定压注释还是拆） |
| `npm run check:rules` | 约束机械检查（密钥 / 版本号 / 易漂数字 / 卫生…） |
| `npm run package` | 打包便携版 → `dist-portable/Harbor` |
| `npm run release:zip` · `release:upload` · `release:prune` | 打 zip · 建 Release · 清旧 Release（prune 默认 dry-run） |
| `npm run shot:electron` | 给打包版截图（`--js=` 先点按钮、`--type=` 敲真键盘） |
| `npm run errors` | 看现在有哪些错误（`--export=` 写报告） |
| `npm run doctor` · `npm run stats` | 数据体检 · 成功率统计 |
| `npm run acceptance` | 验收 |
| `npm run cold-start` | 冷启动体检：干净副本 → 装依赖 → `preflight`，计时对比 10 分钟预算（**手动跑**，不进 CI，见 `scripts/cold-start.mjs`） |
| robocopy（写法见 [`发布检查.md`](发布检查.md) 第 6 步） | 同步到 `E:\Harbor`（两边都排除 `data/`） |

## 六、这一轮新踩的坑（`AGENT.md` 和 [`踩坑记录.md`](踩坑记录.md) 之外）

- **侧栏行只有「当前选中」那行带 `aria-current`** —— 拿它找目标行必然点到旧行。
  正解：先在搜索框打字筛选，再对最内层含目标文字的元素 `closest('[role="button"],li')` 点；
  **判断切换成功要看消息区内容**（`div[tabindex="-1"]` 的 `innerText` / `[data-message-id]` 数），
  别看 `aria-current`。光这一条我误判了两轮。
- **启动动画 ≠ 开屏**：启动动画是 `[role="status"][aria-label*="正在启动"]`（`BootSequence`，会画 canvas，
  默认整段 ~10 秒）；开屏是 `[data-launch-screen="true"]`（`LaunchScreen`，挂载时会跑工作区 / 任务 / 凭据 IPC）。
  量启动相关的东西要等够 10 秒，否则画布动画一直在烧 CPU（Profile 里会是一片 `fillText` / `fillRect`）。
- **别用「mtime 最近 N 分钟」当清理依据** —— 上一轮收尾就这么删掉了两个性能夹具（测试会往夹具里追加流式消息，
  它们的 mtime 永远是新的）。
- **`AGENT.md` 有 6000 字符注入上限**（`electron/core/project.cjs` 的 `MAX_CHARS`，超了截断并告知模型）。
  现在它是 5038 字符 —— **重要规矩写在前面**，别在末尾追加长段。
- **`npm.ps1` / `npx.ps1` 被本机执行策略挡** → 用 `npm.cmd`，或直接 `node <脚本路径>`。
- 时间线探针要带 `startTime`（只记 `duration` 看不出长任务发生在哪一刻）。
- 探针指向别的安装：用 `HARBOR_APP=E:/Harbor` 指定（PowerShell 里 `$env:` 的引号会被吃掉，
  所以走命令行参数）。**注**：这里原来指的 `tmp/perf/probe-real.cjs` 已不在仓库，
  要用得自己按 [`性能基准.md`](性能基准.md) 的口径写一个。
