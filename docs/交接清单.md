| 位置 | 角色 | 规矩 |
|---|---|---|

## 二、在 Harbor 里干活前的三步设置（点一下就好）

`E:\Harbor` 现在还是「刚装上」的默认配置，要让它能改这个仓库，需要：

1. **工作目录** = `E:\CodexWorkbench`（设置 → 通用 → 工作目录）。
   这样每轮对话会自动注入仓库里的 `AGENT.md`（见 `electron/core/project.cjs`）。
2. **Shell 超时** 从默认 60 秒调到 **300 秒以上**（设置 → 工具）。
   否则 `npm run verify`（约 2–3 分钟）和 `node tmp/release-build.cjs` 会被掐断。
3. **文件范围**：确认是「已授权 / 工作目录」（默认 `fileScope: granted` + `permission: full` 就够改仓库）。

三处都能在设置页改，改完**不用重启**。第 1、2 条也可以用现成脚本一把改掉：

```bash
node tmp/setup-harbor-for-dev.cjs          # 先看要改什么（Harbor 在跑就拒绝执行）
node tmp/setup-harbor-for-dev.cjs --apply
```

## 六、这一轮新踩的坑（`AGENT.md` 和 [`踩坑记录.md`](踩坑记录.md) 之外）

- **侧栏行只有「当前选中」那行带 `aria-current`** —— 拿它找目标行必然点到旧行。
  正解：先在搜索框打字筛选，再对最内层含目标文字的元素 `closest('[role="button"],li')` 点；
  **判断切换成功要看消息区内容**（`div[tabindex="-1"]` 的 `innerText` / `[data-message-id]` 数），
  别看 `aria-current`。光这一条我误判了两轮。
- **启动动画 ≠ 开屏**：启动动画是 `[role="status"][aria-label*="正在启动"]`（`BootSequence`，会画 canvas，
  默认整段 ~10 秒）；开屏是 `[data-launch-screen="true"]`（`LaunchScreen`，挂载时会跑工作区 / 任务 / 凭据 IPC）。
  量启动相关的东西要等够 10 秒，否则画布动画一直在烧 CPU（Profile 里会是一片 `fillText` / `fillRect`）。
- **别用「mtime 最近 N 分钟」当清理依据** —— 上一轮收尾就这么删掉了两个性能夹具（测试会往夹具里追加流式消息，
  它们的 mtime 永远是新的）。
- **`AGENT.md` 有 6000 字符注入上限**（`electron/core/project.cjs` 的 `MAX_CHARS`，超了截断并告知模型）。
  现在它是 5038 字符 —— **重要规矩写在前面**，别在末尾追加长段。
- **`npm.ps1` / `npx.ps1` 被本机执行策略挡** → 用 `npm.cmd`，或直接 `node <脚本路径>`。
- 时间线探针要带 `startTime`（只记 `duration` 看不出长任务发生在哪一刻）。
- 探针指向别的安装：`HARBOR_APP=E:/Harbor node tmp/perf/probe-real.cjs E:/Harbor`
  （PowerShell 里 `$env:` 的引号会被吃掉，所以走命令行参数）。
